조사·제작·검수·등록·QA 각 단계가 결과를 파일로 남기고 다음 단계가 읽습니다. 검수를 못 넘은 것은 다음으로 못 갑니다.

만든 것

쿠팡·스마트스토어 위탁판매 자동화

문제
1~3인 위탁판매 셀러는 상품을 올리는 것보다 그 뒤가 무겁습니다. 발주를 손으로 하고, 원 판매처가 품절되면 판매자 책임 취소로 점수를 잃습니다.
만든 것
네이버에서 고른 상품을 AI가 쿠팡 정책에 맞게 다시 써서 두 마켓에 올리고, 등록 전 점검으로 반려를 미리 잡는 설치형 맥 앱. Electron 화면, node 데몬, 일꾼 프로세스, Redis 큐, 크롬 확장.
결과
고객 맥북에서 시운전으로 쿠팡 3건 실등록(2026-09). 유료 운영·매출은 아직 없습니다. 돈이 나가는 버튼과 올리는 버튼은 사람이 누릅니다.

24시간 디지털 상품 무인 루프

문제
디지털 상품은 하나 팔려면 조사·제작·영어 검수·등록·홍보 글·품질 확인을 매번 손으로 돌려야 합니다. 혼자서는 하루 1~2개가 한계입니다.
만든 것
집 PC에서 2시간마다 깨어나는 AI 에이전트 루프. 조사, 제작, 영어 검수, Gumroad 등록, 홍보 글, 자동 QA, 주간 KPI 집계까지 사람 없이 한 바퀴를 돕니다.
결과
Gumroad 공개 상품 15개. 사람이 손대는 것은 주간 KPI 확인뿐입니다.

가계부 방 + 에이전트 방 PWA (웹 푸시, 사설망 전용)

문제
가계부와 에이전트 상태를 폰에서 보고 싶은데, 앱스토어 심사와 네이티브 앱 2벌은 과하고 인터넷에 열어 두기는 싫었습니다.
만든 것
홈 화면에 설치되는 PWA. 가계부 방과 에이전트 방, 웹 푸시 알림. Tailscale 사설망 안에서만 열리고 공개 포트가 없습니다.
결과
매일 쓰는 중. 앱스토어 없이 배포.

파는 것

위 루프가 만든 디지털 상품: 한국 여행 카드, 한글 쓰기 연습지, 한국 전통 무늬 타일, UI 효과음. Gumroad에서 보기.

일하는 방식

  • 돈이 나가는 버튼은 사람이 누릅니다.
  • 토큰·비밀번호는 코드와 문서에 적지 않습니다.
  • AI 에이전트와 함께 제가 직접 설계하고 만들었습니다.
